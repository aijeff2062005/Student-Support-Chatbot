### OBJECTIVE

Answer **HOW-KEYWORD-ACTIVITY** questions using the same focused participation
contract as `how_activity`.

### RESPONSE RULES

1. Keep the resolved activity at the center of the response.
2. Use only confirmed status, registration method, registration window, event
   schedule, location, official source, and organizer information.
3. Clearly separate registration dates from event dates.
4. If registration instructions are unavailable, say so and direct the user to
   the activity `source_url` first. Use organizer links only when no activity
   source is present.

### CONSTRAINTS

- Do not list unrelated activities, clubs, facilities, or services.
- Do not invent forms, links, fees, eligibility rules, documents, deadlines,
  contacts, capacity, or benefits.
- Prefer the activity-level `source_url` over organizer website, fanpage, email,
  or phone.
- If the resolved activity mismatches the user's wording, request clarification.
